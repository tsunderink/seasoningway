# 地圖引擎路線圖

現行行為見 [tripmap.md](tripmap.md)。

## 地圖頁仍依賴日本資料或自駕的部分

2026-11-25地圖頁抽成引擎：每趟只放 `map/config.json` 和 `places/`，標題、類別、評分網站、季節推薦度、開車參數、底圖範圍都在設定裡。剩下這些還沒通用：

| 哪裡 | 綁著什麼 |
|---|---|
| `basemap_tiles.py` | 鐵路讀國土數值情報 N02、地名取 `name:ja`、排除東京 23 區（日本限定）；範圍要手寫在設定的 `basemap` |
| `map/regions.json` | 每趟自己準備，沒有產生的程式（日本的可以從 dataofjapan/land 轉） |
| 開車 | 只算自駕（取還車點之間）；大眾運輸還沒做 |
| `roads.py` | 冬季封路的月份是北半球的 12–3 月（`WINTER`） |
| `plan_drive.py` | 用 OSRM 公開伺服器；公休只認中文「週X」和日文「X曜」 |
| `place_ids.py` | Google Maps demo key 的額度有限，只查排進行程的點 |
| `template.html` | 介面文字是繁體中文；類別圖示內建一組，設定裡的類別沒有對應圖示就畫圓點 |
| 照片 | 搜尋和下載腳本沒放進 repo |

## 之後的方向

- 底圖範圍依地點的經緯度自動算（細緻一層＋外圍一層，外圍要大到能看全程）。OpenStreetMap（Protomaps）全球通用，日本以外只要換掉鐵路和行政界的資料，並先查授權。
- 大眾運輸改用車站距離或步行時間。
- 照片腳本、`regions.json` 的產生程式放進 repo。
- 依第二趟的實際需求決定哪些要可設定，不要只靠一個例子猜。
